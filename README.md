# Vet Social

### Sistema de gestão e atendimento para clínicas veterinárias públicas e organizações de proteção animal.

O **Vet Social** é um projeto que busca desenvolver uma solução digital para auxiliar na organização de atendimentos, informações e acompanhamento de animais em clínicas veterinárias públicas e ONGs.

## Objetivo

Facilitar a organização dos atendimentos veterinários e centralizar informações importantes sobre os animais, contribuindo para um atendimento mais organizado e eficiente.

##  Público-alvo

* Clínicas veterinárias públicas
* ONGs de proteção animal
* Profissionais e equipes veterinárias
* Voluntários
* Tutores e responsáveis pelos animais

##Funcionalidades

As funcionalidades serão definidas durante o desenvolvimento do projeto. Entre as possibilidades estão:

* Cadastro de animais e tutores
* Agendamento de consultas
* Gestão de atendimentos
* Histórico do animal
* Acompanhamento de tratamentos
* Controle de vacinas e procedimentos
* Gestão de animais resgatados

## Documentação

O projeto será documentado ao longo do desenvolvimento, incluindo as etapas de:

**Pesquisa → UX/UI → Desenvolvimento → Testes → Melhorias**

##  Status
